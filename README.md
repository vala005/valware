A single-page, cyberpunk-themed portfolio built to showcase my work as a
Year 3 Computer Science student — web applications, graphic design, and
everything in between. Dark UI, neon cyan/magenta accents, terminal-style
panels, and a glitching hero title, built entirely in vanilla HTML, CSS,
and JS — no frameworks, no build step.
